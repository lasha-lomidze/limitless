# LIMITLESS

LIMITLESS is a collection of fun, human benchmark-style games designed to test and track cognitive abilities such as memory recall, visual accuracy, and reaction time.

## Installation

To run LIMITLESS locally, you will need Python installed on your system.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/lasha-lomidze/limitless.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd limitless
    ```
3.  **Create and activate a virtual environment (recommended):**
    ```bash
    # On macOS/Linux
    python3 -m venv venv
    source venv/bin/activate

    # On Windows (Command Prompt)
    python -m venv venv
    .\venv\Scripts\activate
    ```
4.  **Install the required dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

## Usage

After completing the installation steps, you can start the web server.

1.  **Run the Flask application:**
    ```bash
    python app.py
    ```
2.  **View in browser:**
    The application will be accessible in your web browser. Open your favorite browser and navigate to the address displayed in your terminal (typically `127.0.0.1`).
